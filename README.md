# End-Panel Sign Studio

Free, print-ready shelf end-panel sign designer for public libraries anywhere. Pick a collection, choose one of five templates, and export 300 DPI PNG, exact-size PDF, print-shop PDF with bleed, or print directly.

**Live app:** https://endpanelmaker.civicplexus.org

## Features
- 9 collection presets (Dewey and Library of Congress), 5 templates, custom colors and fonts (including Noto and right-to-left scripts)
- US and A-series sizes, custom sizes, inches or centimeters
- Saved signs, CSV batch runs, JSON backup, multi-page and two-sided PDFs
- Preflight checks, contrast and viewing-distance warnings, QR codes and Braille reference
- Optional branch sharing and AI wording helper (signed-in)
- Editor in English, Spanish and French
